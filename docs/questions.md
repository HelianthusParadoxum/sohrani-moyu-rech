# Вопросы по правилам

Здесь собраны места, где правила неоднозначны. Для каждого принято решение по умолчанию; большинство чисел вынесено в `RULES` (`src/engine/content.ts`).
Ответы автора записывайте прямо сюда, под вопросом.

## Открытые вопросы

1. **Сколько Ростков должно дорасти до 3-й ступени для Гласности?** В разделе «Конец игры» написано: «Если все выложенные Ростки НЕ развиты хотя бы до 3-й ступени — Гласность НЕ наступила». Буквально это читается как «ни один не развит». Но разделы «Куратор», «Громоотвод», «Срез» и одиночный режим требуют, чтобы до 3-й ступени доросли *все* Ростки.
   *Сейчас:* нужны все Ростки (`RULES.glasnostAllSprouts`). *Предлагаемая формулировка:* «Если хотя бы один выложенный Росток не развит до 3-й ступени — Гласность не наступила».
2. **Срез Куратора при равенстве Ростков.** В разделе «Куратор» выбирает Куратор, а в разделе «Конец игры» — «по порядку, в котором Ростки выложены».
   *Сейчас:* по порядку выкладки.
3. **Можно ли продать на Толкучке Нагрузку?** Теперь цена считается за книгу: «+1т — книга без подцензурного жанра». У Нагрузки жанра нет вовсе. Улики по правилам не продаются («ноль подпольного спроса»), Пропаганду можно сбыть только в Красном уголке.
   *Сейчас:* продаются только книги с жанровым значком; Нагрузку продать нельзя.

## Упрощения в цифровой версии

- **Двужанровая книга с возвращёнными смыслами.** По правилам жанр добавленного значка можно выбирать заново в каждой ситуации. Сейчас он выбирается один раз, при возвращении. Гибкий значок можно добавить позже.
- **Автоматический пас** «когда некуда отправить Единомышленника» не определяется. Игрок всегда может пойти в Красный уголок, а после него — спасовать сам.

## Закрыто в редакции правил октября 2026

Состав карт (8 одиночных + 2 шедевра в жанре, 5 + 2 Улики, итого 105), возвращённая Нагрузка (2 + 1 = 3 значка), Возвращение смыслов (бесплатно, только своим книгам, одна накладка на книгу), Подписка (по Пятилеткам), отказ на Квартирнике (действие тратится), пас (только после Красного уголка, до конца Пятилетки), Тиражирование (любая открытая книга), облава не трогает книги взакрытую, Толкучка (−2т за книгу; +2т/+1т за книгу), порядок хода (иначе случайный).
