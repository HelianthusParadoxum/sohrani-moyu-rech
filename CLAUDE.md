# Сохрани мою речь — цифровая версия

Онлайн-версия настольной игры (размещение работников, 1–4 игрока, 5 раундов) для плейтестов. Автор правил — Дмитрий Трубицын.
Общение с владельцем репозитория — на русском. Владелец не программист: объясняйте просто.

## Где что лежит

- `docs/source/` — исходные PDF правил и списков книг и их текстовые версии (`*.txt`, `pdftotext -layout`). Читайте `.txt`, а не PDF: так дешевле.
- `docs/questions.md` — неоднозначности правил и принятые решения. Новые находки дописывайте туда.
- `src/data/cards.json` — карты книг, генерируются из PDF: `npm run data` (`tools/build_cards.py`, ручные правки названий — там же).
- `src/engine/` — движок правил на чистом TypeScript, без сети и UI:
  - `types.ts` — состояние и действия; `content.ts` — адреса, Ростки, Пристрастия и числа баланса (`RULES`);
  - `engine.ts` — `createGame` / `applyAction` (возвращает новое состояние, ошибки правил — `RuleError` с русским текстом);
  - `scoring.ts` — финальный подсчёт; `view.ts` — что видит конкретный игрок (скрытие тайной информации);
  - `bot.ts` — `botMove` / `playOut` и простой случайный бот (пресет «Случайный», запасной вариант);
  - `bot-smart.ts` — думающий бот: примеряет ходы на копии партии и выбирает лучший по оценке. Закрытые карты при примерке
    перемешивает заново (не подглядывает — это проверяет тест). В полном режиме знает Клуб, Контору и решения Завсегдатаев;
    Куратор у него играет против Гласности (`evaluateCurator`);
  - `bot-presets.ts` — пресеты ботов (веса целей по Пятилеткам, характер, включая агрессивность в полном режиме) и базовые
    оценки `BOT_BASE`. Пресет бота выбирается в лобби.
- `src/server/index.ts` — сервер Node: раздаёт `dist/`, комнаты по WebSocket (`/ws`), сохраняет партии в `data/games/`.
- `src/client/` — React-клиент (Vite).
- `tests/` — vitest. `tools/simulate.ts` — симуляция ботами.

## Команды

- `npm test` — тесты; `npm run typecheck` — проверка типов.
- `npm run dev` — сервер (8787) и Vite (5173) с прокси на `/ws`.
- `npm run build && npm start` — продакшен-сборка и запуск.
- `npm run simulate -- 200 3` — 200 партий ботами на 3 игроков (режим — 3-й аргумент: `beginner`, `full` или `reserve`).
- `npm run simulate -- 100 4 beginner networker,gardener,collector,bookman` — турнир пресетов (места сдвигаются по кругу).
- `npm run addresses -- 60 4 bookman,networker,collector,gardener full` — посещаемость адресов за Пятилетку на столе и заполненность мест (пресеты по местам, режим `beginner` или `full`).
- `npm run club -- 300 4 bookman,bookman*2` — Клуб глазами ботов (полный режим): A/B-тест веса Клуба (`*2` — вдвое, `*0` — не ценит) и статистика по Завсегдатаям.
- `npm run patrons -- 40 4` — цена связи с каждым Завсегдатаем: пары партий с одной раздачей, со связью с начала партии и без. Долгий: запускайте в несколько процессов (5-й и 6-й аргументы — смещение партий и файл), затем `npm run patrons -- merge файлы…`.

## Состояние

Два режима: «Райцентр» (`beginner`) и полный (`full`). Логика полного режима (Клуб, Завсегдатаи, Контора, особенности жанров) —
в `src/engine/full.ts`, проверка связи с Завсегдатаем — `hasPatron`. Интерфейс полного режима — `src/client/full-ui.tsx`.
Клуб книголюбов сейчас — свободное действие (`RULES.clubFreeGift`, действие `clubGift` в фазе поручений, `state.freeHold` не даёт
передать ход, пока идут вызванные им решения).
«Заповедник» (`state.reserve`, в лобби — отдельный пункт режима): полный режим без Конторы и Куратора; что есть в партии —
`addressInGame` / `groupInGame` в `content.ts`, удержаний нет (`holdWorker`).
Один игрок — режим «Несистемный» (`state.solo`): 3 Ростка (в Райцентре 2), Цензура +1 за Пятилетку, лишний жетон жанра (`soloPressure` в `engine.ts`),
в конце вскрытие 30 Непечатных (в Райцентре 10) (`soloResult` в `scoring.ts`).
6 сложных Завсегдатаев не реализованы (`implemented: false` в `PATRONS`) и не попадают в партию.

## Принципы

- Любое изменение правил идёт через движок и покрывается тестом. Клиенту никогда не доверяем.
- Тайная информация не должна попадать в `viewFor` для чужих игроков. Проверяйте это тестами.
- Числа баланса держите в `RULES`, чтобы автор мог менять их без чтения кода.
