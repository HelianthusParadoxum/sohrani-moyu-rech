# Сохрани мою речь: книжное подполье СССР — онлайн

Цифровая версия настольной игры Дмитрия Трубицына для онлайн-плейтестов. 2–4 игрока, игра в браузере по ссылке. Свободные места можно занять ботами.

Готовы оба режима: **«Райцентр»** для начинающих и **полные правила**: Клуб книголюбов с Завсегдатаями, Контора, Куратор и особенности жанров. Шесть самых сложных Завсегдатаев пока не запрограммированы и в партию не попадают (список — в [docs/questions.md](docs/questions.md)).

Спорные места правил и решения, принятые по умолчанию, собраны в [docs/questions.md](docs/questions.md).

## Как сыграть

1. Откройте сайт игры, введите имя и нажмите «Создать комнату».
2. Скопируйте ссылку комнаты и отправьте тестировщикам. Они вводят имя и садятся за стол.
3. Если игроков не хватает, хост может добавить ботов. Затем нажмите «Начать партию».
4. У хоста есть кнопка «↶ Отмена»: она отменяет последнее действие, если кто-то ошибся.

## Публикация в интернете (Render, бесплатно)

1. Зарегистрируйтесь на [render.com](https://render.com) через аккаунт GitHub.
2. Нажмите **New → Blueprint** и выберите репозиторий `sohrani-moyu-rech`. Render прочитает файл `render.yaml` и всё настроит сам.
3. Через несколько минут появится адрес вида `https://sohrani-moyu-rech.onrender.com`. Это и есть ссылка на игру.
4. После каждого изменения в ветке `main` сайт обновляется автоматически.

Ограничения бесплатного тарифа: если на сайт никто не заходит 15 минут, сервер засыпает. Первое открытие после этого занимает около минуты, а незаконченные партии при засыпании теряются. Для плейтеста это обычно не мешает. Если начнёт мешать, есть платный тариф с постоянным диском.

## Для разработки

```bash
npm install
npm run dev        # сервер и клиент с автообновлением: http://localhost:5173
npm test           # тесты движка
npm run simulate -- 200 3   # 200 партий ботами на троих
```
